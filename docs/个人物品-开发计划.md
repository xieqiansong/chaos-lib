# 个人物品管理工具 —— 完整方案

---

## 一、整体设计

**四张核心表 + 一张装配关系表**：

| 表 | 作用 |
|---|---|
| `category` | 分类字典（支持父子级） |
| `location` | 存放位置字典（支持父子级） |
| `item` | 物品主表（耐用品 + 消耗品统一存） |
| `item_record` | 变动流水（购入/消耗/补货/借出/维修/装配/拆卸…） |
| `item_assembly` | 装配关系（电脑挂硬盘/内存/网卡等配件） |

**三条设计原则**：
1. **耐用品和消耗品共用主表**，用 `item_type` 区分，避免 UNION。
2. **`item` 表平铺**，配件也是独立 item，装配关系单独记，保留完整流转历史。
3. **耐用品记"事件"，消耗品记"周期"**——不逼用户记每一次消耗，只在补货时顺手结掉上一批。

## 二、完整建表语句

```sql
CREATE DATABASE IF NOT EXISTS my_items
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
USE my_items;

-- ===============================================================
-- 1. 分类表（支持父子级，如 数码 > 手机）
-- ===============================================================
CREATE TABLE category (
  id          INT UNSIGNED NOT NULL AUTO_INCREMENT,
  parent_id   INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '父分类ID，0=顶级',
  name        VARCHAR(50)  NOT NULL COMMENT '分类名',
  icon        VARCHAR(50)  DEFAULT NULL COMMENT '图标标识，前端用',
  sort_order  INT          NOT NULL DEFAULT 0,
  created_at  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_parent (parent_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='物品分类';

-- ===============================================================
-- 2. 存放位置表（支持父子级，如 家 > 书房 > 抽屉A）
-- ===============================================================
CREATE TABLE location (
  id          INT UNSIGNED NOT NULL AUTO_INCREMENT,
  parent_id   INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '父位置ID，0=顶级',
  name        VARCHAR(50)  NOT NULL,
  sort_order  INT          NOT NULL DEFAULT 0,
  created_at  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_parent (parent_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='存放位置';

-- ===============================================================
-- 3. 物品主表（耐用品 + 消耗品统一存）
-- ===============================================================
CREATE TABLE item (
  id               BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  name             VARCHAR(100)    NOT NULL COMMENT '物品名称',
  category_id      INT UNSIGNED    DEFAULT NULL,
  location_id      INT UNSIGNED    DEFAULT NULL,

  item_type        TINYINT         NOT NULL DEFAULT 1
                   COMMENT '1=耐用品 2=消耗品',

  brand            VARCHAR(50)     DEFAULT NULL COMMENT '品牌',
  model            VARCHAR(80)     DEFAULT NULL COMMENT '型号',
  spec             VARCHAR(100)    DEFAULT NULL COMMENT '规格/容量',
  color            VARCHAR(30)     DEFAULT NULL,

  quantity         DECIMAL(10,2)   NOT NULL DEFAULT 1.00 COMMENT '当前数量',
  unit             VARCHAR(10)     NOT NULL DEFAULT '个' COMMENT '单位',
  min_quantity     DECIMAL(10,2)   DEFAULT NULL COMMENT '低库存提醒阈值(消耗品用)',

  status           VARCHAR(20)     NOT NULL DEFAULT 'in_use'
                   COMMENT 'in_use在用/idle闲置/lent借出/repairing维修/broken损坏/disposed已处置',

  serial_no        VARCHAR(80)     DEFAULT NULL COMMENT '序列号/IMEI/资产编号',
  purchase_date    DATE            DEFAULT NULL COMMENT '购买日期',
  purchase_price   DECIMAL(10,2)   DEFAULT NULL COMMENT '购买价格',
  purchase_channel VARCHAR(50)     DEFAULT NULL COMMENT '购买渠道',
  warranty_end     DATE            DEFAULT NULL COMMENT '保修到期日',
  expire_date      DATE            DEFAULT NULL COMMENT '保质期/到期日',

  last_replenish_date DATE         DEFAULT NULL COMMENT '最近一次补货日期(消耗品用)',
  last_replenish_qty  DECIMAL(10,2) DEFAULT NULL COMMENT '最近一次补货数量(消耗品用)',

  tags             VARCHAR(200)    DEFAULT NULL COMMENT '逗号分隔标签',
  cover_image      VARCHAR(255)    DEFAULT NULL COMMENT '封面图URL',
  remark           VARCHAR(500)    DEFAULT NULL COMMENT '备注',

  created_at       DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at       DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP
                                   ON UPDATE CURRENT_TIMESTAMP,
  deleted_at       DATETIME        DEFAULT NULL COMMENT '软删除，NULL=未删除',

  PRIMARY KEY (id),
  UNIQUE KEY uk_serial (serial_no),
  KEY idx_category (category_id),
  KEY idx_location (location_id),
  KEY idx_type_status (item_type, status),
  KEY idx_name (name),
  KEY idx_warranty (warranty_end),
  KEY idx_expire (expire_date),
  KEY idx_replenish (last_replenish_date),
  KEY idx_deleted (deleted_at),

  CONSTRAINT fk_item_category FOREIGN KEY (category_id)
    REFERENCES category(id) ON DELETE SET NULL,
  CONSTRAINT fk_item_location FOREIGN KEY (location_id)
    REFERENCES location(id) ON DELETE SET NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='物品主表';

-- ===============================================================
-- 4. 变动流水表（所有"发生过的事"都记这里）
-- ===============================================================
CREATE TABLE item_record (
  id           BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  item_id      BIGINT UNSIGNED NOT NULL,

  record_type  VARCHAR(20)     NOT NULL
               COMMENT 'purchase购入/consume消耗/replenish补货/'
                       'lend借出/return归还/repair维修/move转移/'
                       'dispose处置/inventory盘点/install装入/remove拆下',

  quantity     DECIMAL(10,2)   DEFAULT NULL COMMENT '本次变动数量',
  amount       DECIMAL(10,2)   DEFAULT NULL COMMENT '涉及金额',
  record_date  DATE            NOT NULL COMMENT '发生日期',
  note         VARCHAR(300)    DEFAULT NULL COMMENT '备注',

  created_at   DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP,

  PRIMARY KEY (id),
  KEY idx_item_date (item_id, record_date),
  KEY idx_type (record_type),

  CONSTRAINT fk_record_item FOREIGN KEY (item_id)
    REFERENCES item(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='物品变动流水';

-- ===============================================================
-- 5. 装配关系表（电脑挂配件 / 自行车挂零件等）
-- ===============================================================
CREATE TABLE item_assembly (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  host_id       BIGINT UNSIGNED NOT NULL COMMENT '主机(电脑准系统等) item.id',
  component_id  BIGINT UNSIGNED NOT NULL COMMENT '配件(硬盘/内存/网卡) item.id',

  slot          VARCHAR(50)     DEFAULT NULL COMMENT '槽位，如 DIMM_A1 / M.2_1',
  quantity      DECIMAL(10,2)   NOT NULL DEFAULT 1.00 COMMENT '装配数量',

  installed_at  DATE            NOT NULL COMMENT '装配日期',
  removed_at    DATE            DEFAULT NULL COMMENT '拆卸日期，NULL=当前仍在位',
  install_note  VARCHAR(200)    DEFAULT NULL,
  remove_note   VARCHAR(200)    DEFAULT NULL,

  created_at    DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at    DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP
                                ON UPDATE CURRENT_TIMESTAMP,

  PRIMARY KEY (id),
  KEY idx_host_current (host_id, removed_at),
  KEY idx_component (component_id, removed_at),

  CONSTRAINT fk_asm_host FOREIGN KEY (host_id)
    REFERENCES item(id) ON DELETE CASCADE,
  CONSTRAINT fk_asm_component FOREIGN KEY (component_id)
    REFERENCES item(id) ON DELETE CASCADE,
  CONSTRAINT chk_no_self CHECK (host_id <> component_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='物品装配关系';
```

### 可选增强：一个配件同一时间只能装在一处

```sql
ALTER TABLE item_assembly
  ADD COLUMN current_host_id BIGINT UNSIGNED
    GENERATED ALWAYS AS (IF(removed_at IS NULL, host_id, NULL)) STORED,
  ADD UNIQUE KEY uk_component_current (component_id, current_host_id);
```

> 原理：唯一索引里 `NULL` 不冲突。在位时 `current_host_id = host_id`（唯一），已拆时 `= NULL`（可多条历史）。
> 只适合"一个 item = 一个物理实体（有序列号）"的配件。

## 四、操作逻辑（按场景）

### 场景 1：新购入一件耐用品

```sql
-- 记录物品本身
INSERT INTO item (name, category_id, location_id, item_type, brand, model,
                  serial_no, purchase_date, purchase_price, warranty_end, status)
VALUES ('主力笔记本', 3, 2, 1, 'Apple', 'MacBook Pro 14',
        'C02XXXXXXX', '2024-03-15', 15999.00, '2026-03-15', 'in_use');

-- 记录购买流水
INSERT INTO item_record (item_id, record_type, record_date, amount, note)
VALUES (LAST_INSERT_ID(), 'purchase', '2024-03-15', 15999.00, 'Apple 官网');
```

---

### 场景 2：加装配件（硬盘/内存/网卡）

**前提**：配件本身也是独立 item（有序列号、可单独保修）。

```sql
-- 先建配件 item（若还没建）
INSERT INTO item (name, category_id, item_type, brand, model, spec,
                  serial_no, purchase_date, purchase_price, warranty_end, status)
VALUES ('2T 固态硬盘', 4, 1, 'Samsung', '990 Pro', '2TB',
        'S6XXXX', '2024-04-01', 999.00, '2029-04-01', 'in_use');

-- 建立装配关系（假设主机 id=100，配件 id=205）
START TRANSACTION;

INSERT INTO item_assembly (host_id, component_id, slot, installed_at, install_note)
VALUES (100, 205, 'M.2_1', CURDATE(), '加装 2T 固态');

-- 配件位置跟随主机
UPDATE item
SET location_id = (SELECT location_id FROM item WHERE id = 100),
    status = 'in_use'
WHERE id = 205;

INSERT INTO item_record (item_id, record_type, record_date, note)
VALUES (205, 'install', CURDATE(), '装入主机 #100');

COMMIT;
```

---

### 场景 3：拆下配件（换机/闲置）

```sql
START TRANSACTION;

UPDATE item_assembly
SET removed_at = CURDATE(), remove_note = '拆下换到备用机'
WHERE component_id = 205 AND removed_at IS NULL;

UPDATE item SET status = 'idle' WHERE id = 205;

INSERT INTO item_record (item_id, record_type, record_date, note)
VALUES (205, 'remove', CURDATE(), '从主机 #100 拆下');

COMMIT;
```

---

### 场景 4：消耗品用完清零（可选操作）

```sql
-- 应用层读出当前 quantity=2，用户点"用完"
START TRANSACTION;

UPDATE item SET quantity = 0 WHERE id = 7;

INSERT INTO item_record (item_id, record_type, quantity, record_date, note)
VALUES (7, 'consume', 2, CURDATE(), '用完清零');

COMMIT;
```

> `consume` 的 `quantity` = 本次消耗掉的数量。

---

### 场景 5：消耗品补货（**核心动作，一次搞定**）

用户习惯：平时什么都不记，只在**用完去买**时操作一次。

```sql
-- 假设旧库存 quantity=1，用户补货 5 包
START TRANSACTION;

-- ① 清理上一批（若旧库存 > 0）
INSERT INTO item_record (item_id, record_type, quantity, record_date, note)
VALUES (7, 'consume', 1, CURDATE(), '补货时清上一批');

-- ② 进新货 + 更新主表冗余字段
UPDATE item
SET quantity            = 5,
    last_replenish_date = CURDATE(),
    last_replenish_qty  = 5
WHERE id = 7;

INSERT INTO item_record (item_id, record_type, quantity, amount, record_date, note)
VALUES (7, 'replenish', 5, 39.90, CURDATE(), '京东购入');

COMMIT;
```

> 若用户懒到极点，默认"上次已用完"，第 ① 步直接生成 `consume(旧库存)`。

---

### 场景 6：盘点修正

```sql
-- 系统记录 5，实际数了数还剩 3 → 差额 2 记为消耗
START TRANSACTION;

UPDATE item SET quantity = 3 WHERE id = 7;

INSERT INTO item_record (item_id, record_type, quantity, record_date, note)
VALUES (7, 'inventory', 2, CURDATE(), '盘点差异：账面5，实际3');

COMMIT;
```

---

### 场景 7：借出 / 归还

```sql
UPDATE item SET status = 'lent' WHERE id = 50;
INSERT INTO item_record (item_id, record_type, record_date, note)
VALUES (50, 'lend', CURDATE(), '借给张三');

-- 归还时
UPDATE item SET status = 'in_use' WHERE id = 50;
INSERT INTO item_record (item_id, record_type, record_date, note)
VALUES (50, 'return', CURDATE(), '张三归还');
```

## 五、常用查询

### 1. 消耗品库存告急

```sql
SELECT id, name, quantity, unit, min_quantity
FROM item
WHERE item_type = 2 AND deleted_at IS NULL
  AND min_quantity IS NOT NULL AND quantity <= min_quantity;
```

### 2. 消耗品补货周期预测

```sql
SELECT
  item_id,
  COUNT(*)                                        AS cycles,
  ROUND(AVG(DATEDIFF(record_date, prev_date)), 1) AS avg_cycle_days,
  MAX(record_date)                                AS last_buy,
  DATE_ADD(MAX(record_date),
           INTERVAL ROUND(AVG(DATEDIFF(record_date, prev_date))) DAY)
                                                  AS next_buy_estimate
FROM (
  SELECT item_id, record_date,
         LAG(record_date) OVER (PARTITION BY item_id ORDER BY record_date) AS prev_date
  FROM item_record
  WHERE record_type = 'replenish'
) t
WHERE prev_date IS NOT NULL
GROUP BY item_id;
```

### 3. 一台电脑的当前完整配置

```sql
SELECT
  c.name AS component, c.brand, c.model, c.spec, c.serial_no,
  a.slot, a.quantity, a.installed_at
FROM item_assembly a
JOIN item c ON c.id = a.component_id
WHERE a.host_id = 100
  AND a.removed_at IS NULL
  AND c.deleted_at IS NULL
ORDER BY a.slot;
```

### 4. 某个配件的流转历史

```sql
SELECT
  a.host_id, h.name AS host_name,
  a.slot, a.installed_at, a.removed_at,
  CASE WHEN a.removed_at IS NULL THEN '在位' ELSE '已拆' END AS state
FROM item_assembly a
JOIN item h ON h.id = a.host_id
WHERE a.component_id = 205
ORDER BY a.installed_at DESC;
```

### 5. 保修到期提醒（30 天内）

```sql
SELECT name, brand, model, warranty_end,
       DATEDIFF(warranty_end, CURDATE()) AS days_left
FROM item
WHERE deleted_at IS NULL AND warranty_end IS NOT NULL
  AND warranty_end BETWEEN CURDATE() AND DATE_ADD(CURDATE(), INTERVAL 30 DAY)
ORDER BY warranty_end;
```

### 6. 按分类统计在册物品与总价值

```sql
SELECT c.name AS category, COUNT(*) AS cnt,
       SUM(i.purchase_price * i.quantity) AS total_value
FROM item i
JOIN category c ON c.id = i.category_id
WHERE i.deleted_at IS NULL AND i.status <> 'disposed'
GROUP BY c.id, c.name;
```

### 7. 整机价值（主机 + 当前配件）

```sql
SELECT
  h.id, h.name,
  h.purchase_price AS host_price,
  COALESCE(SUM(c.purchase_price * a.quantity), 0) AS parts_price,
  h.purchase_price + COALESCE(SUM(c.purchase_price * a.quantity), 0) AS total
FROM item h
LEFT JOIN item_assembly a ON a.host_id = h.id AND a.removed_at IS NULL
LEFT JOIN item c ON c.id = a.component_id AND c.deleted_at IS NULL
WHERE h.id = 100
GROUP BY h.id;
```

## 六、关键规则速查

### 物品类型判断

| 场景 | 做法 |
|---|---|
| 耐用品（手机/电脑/鼠标） | `item_type = 1`，记事件流水 |
| 消耗品（纸巾/洗衣液） | `item_type = 2`，记补货周期 |
| 有序列号、可单独保修的配件 | 独立 `item` + `item_assembly` |
| 无序列号、不打算拆的配件 | 写进主机 `spec` 字段即可 |

### 流水类型语义

| `record_type` | 含义 | `quantity` 语义 |
|---|---|---|
| `purchase` | 首次购入 | 通常留空 |
| `consume` | 消耗/离开库存 | 本次消耗量 |
| `replenish` | 补货 | 本次补入量 |
| `inventory` | 盘点差异 | 差额（正=少了） |
| `lend` / `return` | 借出 / 归还 | 借出量 |
| `repair` | 维修 | 留空，`amount` 填费用 |
| `install` / `remove` | 装入 / 拆下 | 留空 |
| `dispose` | 处置（卖掉/扔掉） | 留空 |

### 通用约束

1. **先写流水，再更新主表**，放在同一事务里。
2. **主表 `quantity` 是冗余字段**，为查询性能服务；流水表才是真相。
3. **软删除** `deleted_at`，用于"卖掉/扔了"的记录保留；真不要才物理删。
4. **主机被处置时**：先批量给在位的配件写 `removed_at`、`status='idle'`，再处置主机。
5. **配件位置** 同步主机的 `location_id`，物理上它就在主机所在位置。
6. **标签**先用逗号分隔字符串，等要频繁按标签筛选再拆 `tag` + `item_tag`。
7. **多人使用**：给 `item`/`category`/`location` 加 `user_id` 并加索引，结构不变。
8. **多张图片**：再加 `item_image(item_id, url, sort_order)`，主表只留封面图。

---

## 七、一句话总结

> **耐用品记事件，消耗品记周期，配件记装配关系。**
> 三套逻辑共用 `item` 主表，靠 `item_type` 和 `item_assembly` 区分，一套流水表打天下。
